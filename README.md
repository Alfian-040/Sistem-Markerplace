# LOKALO (frontend lengkap)

Sistem Informasi Marketplace Berbasis Web untuk Mendukung Digitalisasi Penjualan Produk UMKM.
Frontend React + Vite. Data disimpan di localStorage browser (backend menyusul).

## Menjalankan

    npm install
    npm run dev

Buka alamat yang tertulis di Terminal (biasanya http://localhost:5173).
